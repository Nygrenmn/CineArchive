# CineArchive

> **University project:** CineArchive - Local Film Collection Manager 

A Java desktop application for managing and reviewing a personal film collection, with focus 
on object-oriented design, database integration, and user interaction.
Inspired by Letterboxd, the application allows users to browse, organize, and review films locally.

## Tech
Java · Swing · MySQL (Sakila) · JDBC · Maven

## Features
- Search and filter films by title, genre, and age rating
- Add films to a personal watchlist and export it as a CSV file
- Import and clear your watchlist
- Write and view film reviews
- Admin panel for:
  - Testing database connection  
  - Running SQL queries  
  - Uploading/downloading CSV files  
  - Adding films to the database
